# **Python Tutorials for University Instructors**

This repository contains a series of tutorials introducing the [Python](https://www.python.org/) programming language. 

Developed as part of the University of Toronto's [Faculty of Arts & Science](https://www.artsci.utoronto.ca/) [Computation & Data Science Education Initiative](https://uoft-cdse.github.io/), these tutorials are intended as a starting point for post-secondary instructors who wish to incorporate programming into their courses. While the materials introduce core programming concepts and skills, instructors are encouraged to adapt and extend them to suit the needs of their own disciplines and teaching contexts. 

In addition to covering the fundamentals of Python, the collection includes tutorials on using Python for data visualization and introductory data analysis. 

All materials have been developed as interactive Jupyter Notebooks. University of Toronto users can use these notebooks through the University's [JupyterHub platform](https://datatools.utoronto.ca/). 

This project is an ongoing work in progress, and we welcome suggestions, feedback, and questions. University of Toronto Faculty of Arts & Science instructors seeking support in using or adapting these materials are encouraged to contact us by [email](mailto:teachinglearning.artsci@utoronto.ca).
